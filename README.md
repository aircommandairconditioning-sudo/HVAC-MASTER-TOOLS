# ❄️ HVAC MASTER TOOLS

**Professional HVAC Engineering Calculators built with Python and Streamlit.**

HVAC MASTER TOOLS is an open-source project designed to help HVAC engineers, technicians and students perform common air-conditioning and refrigeration calculations.

## 🚀 Features

Currently includes 8 calculators:

1. **BTU Calculator** – Estimates room cooling capacity.
2. **TR Calculator** – Converts BTU/hr into Tons of Refrigeration.
3. **CFM Calculator** – Calculates required airflow.
4. **Air Velocity Calculator** – Calculates duct air velocity.
5. **Duct Size Calculator** – Calculates rectangular duct dimensions.
6. **Superheat Calculator** – Calculates refrigerant superheat.
7. **Subcooling Calculator** – Calculates refrigerant subcooling.
8. **Refrigerant Pressure-Temperature Calculator** – Calculates saturation pressure and temperature using CoolProp, with Dew Point and Bubble Point support.

## 🛠️ Technologies Used

- Python
- Streamlit
- CoolProp

## 📥 Installation

Clone this repository:

```bash
git clone https://github.com/aircommandairconditioning-sudo/HVAC-MASTER-TOOLS.git
```

Open the project folder:

```bash
cd HVAC-MASTER-TOOLS
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

```bash
python -m streamlit run app.py
```

The application will open in your web browser.

## 🎯 Project Goal

To build a practical and accessible collection of HVAC engineering tools for professionals, technicians and students.

## ⚠️ Disclaimer

These calculators are intended as engineering assistance tools. Results should be checked against applicable engineering standards, manufacturer specifications and actual operating conditions.

The BTU calculator uses a simplified estimation method and is not a complete cooling-load calculation.
